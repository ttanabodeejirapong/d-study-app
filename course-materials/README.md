# EC214 Course Materials

Storage policy for this repository:

- **Only the five current full annotated professor lecture PDFs are intended to be stored as actual files in this repository.**
- Old exams, old lecture collections, exercises, student notes, textbooks, and other historical materials remain in their original Google Drive locations and are referenced here by link only.
- Professor teaching recordings remain YouTube links only.
- This keeps the app repository smaller and avoids duplicating large third-party archives.
